# AI Quiz Generator for Teachers

A beginner-friendly website that lets teachers create multiple-choice quizzes on AI topics, and lets students take the quiz and see their score with explanations.

> **Demo version:** This project does **not** use a live AI model. Questions come from a small, clearly labelled, built-in demonstration question bank written directly in `script.js`. No API key, account, or backend is needed.

## Features

- Enter a topic, choose a difficulty (Beginner, Intermediate, Advanced) and the number of questions (3, 5 or 6)
- Generates a quiz with four answer options per question
- Students pick answers and submit; the quiz checks that every question is answered
- Shows the score, correct answers, and an explanation for every question
- Reset Quiz button to start over
- Clear message if the topic is empty or has no demo questions
- Responsive layout for phones and computers
- Demo topics: Artificial Intelligence, Machine Learning, Generative AI, Prompt Engineering

## Technology

- HTML (structure)
- CSS (design and responsive layout)
- Vanilla JavaScript (quiz logic, no libraries or frameworks)

## Setup

1. Download or clone this repository.
2. Open `index.html` in any modern browser (double-click it).
3. Type a topic such as `machine learning`, choose options, and click **Generate Quiz**.

No installation is required.

## Host with GitHub Pages

1. Push the project to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder, then click **Save**.
5. After a minute or two, your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Limitations

- Questions are **pre-written samples**, not generated by AI.
- Only four topics are covered, with six questions each (24 in total).
- A topic is matched by keywords, so unrelated topics will show a "no questions" message.
- Scores are not saved, and there is no teacher login, sharing, or export.
